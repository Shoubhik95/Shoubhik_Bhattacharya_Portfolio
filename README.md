## 📖 About

This repository contains the source for my personal portfolio site — a single-page showcase of my work as a **Technical Game Designer & Game Artist**.

I'm a B.Tech CSE (Gaming Technology) student combining a strong artistic eye with hands-on technical skills, leveraging **Unreal Engine 5, Unity, Blender, MetaHuman, and Sequencer** to design cohesive, atmospheric, and player-focused interactive experiences.
